📲 Cara Memasang Grammar Quest

Setelah PIN Anda aktif, ikuti langkah sesuai perangkat dan browser yang dipakai. Setelah terpasang, aplikasi bisa dibuka dari layar utama seperti aplikasi biasa — termasuk tanpa internet.

Catatan umum Tampilan menu bisa sedikit berbeda tergantung versi browser, tapi carilah kalimat yang mirip seperti "Instal aplikasi" atau "Tambah ke Layar Utama". Kalau tidak menemukan menunya sama sekali, aplikasi tetap bisa dipakai penuh langsung dari browser tanpa dipasang — hanya saja tidak muncul ikon di layar utama.

🤖 Android — Google Chrome
  1. Buka tautan situs Grammar Quest di Chrome.
  2. Ketuk menu titik tiga (⋮) di pojok kanan atas.
  3. Pilih "Instal aplikasi" (kadang tertulis "Tambahkan ke Layar Utama").
  4. Ketuk Instal pada jendela konfirmasi yang muncul.
🤖 Android — Browser lain (Samsung Internet, dll.)
  1. Buka situs Grammar Quest di browser tersebut.
  2. Ketuk ikon menu (biasanya garis tiga atau titik tiga).
  3. Cari menu "Tambahkan halaman ke" atau "Tambah ke Layar Utama".
  4. Konfirmasi penambahan ikon.
Sebagian browser Android selain Chrome punya dukungan pemasangan aplikasi yang terbatas. Kalau menunya tidak ditemukan, gunakan Chrome untuk hasil terbaik.
🍎 iPhone / iPad — Safari wajib pakai Safari
  1. Buka tautan situs Grammar Quest menggunakan Safari (bukan Chrome atau browser lain).
  2. Ketuk ikon Bagikan — kotak dengan panah ke atas, di bagian bawah layar (di iPad, ikon ini ada di bagian atas).
  3. Gulir ke bawah pada menu yang muncul, lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah di pojok kanan atas.
Di iPhone/iPad, hanya Safari yang bisa memasang aplikasi ke layar utama — walau Chrome atau browser lain terpasang di HP Anda, tetap gunakan Safari khusus untuk langkah ini.
💻 Windows / Mac — Chrome atau Edge
  1. Buka situs Grammar Quest di Chrome atau Edge.
  2. Perhatikan ujung kanan address bar — akan muncul ikon kecil (layar dengan panah, atau tanda +).
  3. Klik ikon tersebut, atau lewat menu titik tiga (⋮) pilih "Instal Grammar Quest…".
  4. Klik Instal pada jendela yang muncul.
🍏 Mac — Safari
  1. Buka situs Grammar Quest di Safari.
  2. Klik menu File di bilah menu atas, lalu pilih "Tambahkan ke Dock…".
  3. Klik Tambahkan.
Fitur ini tersedia di Safari versi yang mendukung macOS Sonoma ke atas. Kalau menu ini tidak muncul, gunakan Chrome atau Edge di Mac Anda sebagai gantinya.
🦊 Firefox (Desktop)
  1. Firefox versi desktop saat ini belum mendukung pemasangan aplikasi seperti Chrome/Edge.
  2. Anda tetap bisa memakai Grammar Quest sepenuhnya langsung dari Firefox tanpa dipasang.
  3. Untuk bisa memasangnya sebagai aplikasi, buka tautan yang sama di Chrome atau Edge.

Masih mengalami kendala saat memasang? Hubungi kami lewat WhatsApp dari halaman utama, kami bantu langkah demi langkah.
